各作業摘要

作業一：Gmail 自動讀寫程式（25 分）

  • 撰寫 Python 程式，使用 Google 帳戶的 16 字元應用程式密碼登入 Gmail。
  • 透過 IMAP 讀取收件匣最新 N 封信，透過 SMTP 寄信給指定收件者，寄信後再讀信驗證確實收到。
  • 帳號密碼不得寫死在程式碼中；登入失敗要有清楚的錯誤訊息。
  • 範例程式 gmail_auto.py 只用 Python 標準函式庫。

作業二：用 QR Code 導引到網頁（25 分）

  • 撰寫 Python 程式，將任一網址轉成 QR Code 圖片，並自行解碼驗證內容。
  • 在自己的電腦架一個含學號姓名的網頁，產生指向它的 QR Code，至少讓 2 台手機掃描成功並記錄每次連線。
  • 範例程式 qr_web.py，需安裝 qrcode 與 opencv-python-headless。

作業三：海大餐廳候位系統（50 分）

  • 前端（顧客候位頁、員工管理頁）放在自己的 GitHub Pages，後端用 Google Apps Script，不用架伺服器、不用安裝套件、不用資料庫。
  • 候位 Queue 自己寫：JSON 陣列存在 Apps Script 的 PropertiesService，實作 enqueue、positionOf、remove 等方法。
  • 顧客掃 QR Code 進入網頁，填姓名、性別、E-mail 取號，看到前面還有幾組；員工輸入密碼看 queue，按「通知」自動從 Gmail 寄信，按「入座」「取消」移出 queue。
  • 範例：前端 4 個檔案（index.html、staff.html、app.js、waitlist.css）與後端 Code.gs。

報告共同規定

三份作業都要交程式與報告，報告必須包含以下三部分，缺一項即扣分：

  1. 報告題目：自訂一個能表達作業內容的題目，不可只寫「作業一」。
  2. 目的：說明程式要解決什麼問題、預期達成什麼效果（作業一、二 100 到 200 字，作業三 150 到 250 字）。
  3. 報告內容項目：依各作業說明列出的項目逐項撰寫，每一項都要附上自己實際執行的證據（截圖、程式產生的紀錄檔、收到的 E-mail）。抄範例、憑想像寫的結果一律不計分。

範例程式每次執行都會在 results/ 目錄留下這次的真實結果，作業三則可用 ?action=log 取得事件紀錄，寫報告時直接引用。

繳交方式

  • 每份作業各自壓縮成一個 zip，檔名依各作業說明：學號_姓名_gmail作業.zip、學號_姓名_qrcode作業.zip、學號_姓名_候位系統.zip。
  • 作業三另附 GitHub 儲存庫網址與 GitHub Pages 網址。
  • 報告格式 Word、PDF 或 Markdown 皆可。

安全與注意事項

  • 應用程式密碼等同帳號密碼，絕對不可出現在程式碼、報告、截圖或任何繳交檔案中；作業結束後請到 Google 帳戶刪除。
  • 作業三的 STAFF_KEY 與 API_URL 繳交時請改成假的；Apps Script 部署作業用完請封存，Queue 用 ?action=reset 清空。
  • 寄信與 QR Code 測試只能針對自己、同組同學或公開合法的網站，不可對外亂寄或導向有害內容。
  • 本機網站與候位系統只在測試時開啟，測試完請關閉。
