作業二：用 QR Code 導引到網頁

Python 產生 QR Code · 自架網頁 · 手機掃描驗證

一、作業目標 · 二、前置準備 · 三、程式功能要求 · 四、報告要求 · 五、繳交內容 · 六、評分標準 · 七、注意事項

一、作業目標

撰寫一支 Python 程式，將網址轉成 QR Code 圖片，用手機掃描後能正確開啟該網頁；進一步在自己的電腦架一個簡單網頁，產生指向它的 QR Code，讓同學用手機掃描進入，並記錄實際掃描結果。

課程提供 qr_web.py 作為範例，同學可以直接執行、修改，或參考其寫法自行重寫。

二、前置準備

  1. 安裝套件： 
    pip install "qrcode[pil]" opencv-python-headless
  2. 執行測試： 
    python qr_web.py make --url https://www.google.com --out qr_google.png --label "Google"
python qr_web.py decode qr_google.png
python qr_web.py serve --port 8000
  3. serve 模式會在 site/ 目錄建立 index.html（請改成自己的學號、姓名與內容），並產生 qr_site.png。手機連到和電腦相同的 Wi-Fi，掃描後會打開你的網頁，程式會記錄每一次連線（時間、來源 IP、瀏覽器）。按 Ctrl+C 結束。
每次執行都會在 results/ 目錄留下 qr_模式_日期時間.md 與 .json，寫報告時直接引用。

三、程式功能要求

編號要求必要 / 加分
F1輸入任一網址，產生 QR Code 圖片檔（PNG）必要
F2用手機實際掃描，能正確開啟該網頁必要
F3程式自行解碼剛產生的圖片，確認內容與原網址相同必要
F4架設本機網頁，產生指向本機網頁的 QR Code，至少讓 2 台裝置掃描成功必要
F5網頁內容須含自己的學號與姓名，並記錄每一次連線必要
F6比較不同容錯等級（L / M / Q / H）產生的 QR Code 大小與可讀性加分
F7QR Code 加上文字標籤或中央 Logo，且仍可正常掃描加分
F8導引到的網頁有互動功能（表單、簽到、問卷等）加分

四、報告要求

報告使用 Word、PDF 或 Markdown 皆可，必須包含以下三部分，缺一項即扣分。

1. 報告題目

自訂一個能表達本次作業內容的題目，例如：「以 Python 產生 QR Code 導引手機至自架網頁」。不可直接寫「作業二」或「QR Code 報告」。

2. 目的

說明 QR Code 要解決什麼問題（例如讓使用者不必手動輸入網址）、本次程式預期達成的效果，以及為什麼要自己架網頁來驗證。建議 100 到 200 字。

3. 報告內容項目（全部必須依實際執行結果撰寫）

以下每一項都要有自己實際跑出來的證據（執行畫面截圖、產生的 QR Code 圖片、手機掃描截圖，或 results/ 紀錄檔內容）。抄範例、憑想像寫的結果一律不計分。
項目必須包含的內容
3.1 執行環境作業系統、Python 版本、使用的套件與版本、測試用手機型號
3.2 QR Code 原理簡述版本（version）、模組數、容錯等級的意義，用自己產生的 QR Code 實際數值說明
3.3 程式架構說明程式分成哪幾個部分、各部分做什麼、用到哪些函式庫（qrcode、PIL、cv2、http.server 等）
3.4 產生 QR Code 結果產生的圖片、程式印出的版本 / 模組數 / 容錯等級 / 圖片像素 / 檔案大小
3.5 解碼驗證結果程式解碼出的內容與原網址比對結果
3.6 手機掃描結果手機掃描後開啟網頁的截圖，至少 2 台裝置
3.7 本機網站連線紀錄程式記錄到的連線清單（時間、來源 IP、瀏覽器），說明共有幾次、幾台裝置
3.8 錯誤與排除實際遇到的錯誤（例如手機與電腦不同網段、防火牆擋 8000 埠、Logo 太大導致無法掃描）、原因與解法。若完全沒遇到錯誤，請故意把 Logo 放大到無法掃描並記錄
3.9 結論與心得程式是否達成目的、哪裡可以改進、學到什麼

五、繳交內容

  1. 程式原始碼（.py 檔）與網頁檔（site/index.html）
  2. 產生的 QR Code 圖片（至少 2 張）
  3. 報告檔（Word / PDF / Markdown）
  4. results/ 目錄中至少一次 make 與一次 serve 的紀錄檔

壓縮成一個檔案，檔名：學號_姓名_qrcode作業.zip

七、注意事項

  • QR Code 只能導向自己的網頁或公開、合法的網站，不可導向任何有害或侵權內容。
  • 本機網站只在作業測試時開啟，測試完請關閉，不要長時間對外開放。
  • 手機與電腦必須在同一個 Wi-Fi；學校網路若有隔離，請改用手機熱點讓電腦連上再測。
